# Detail-Kits

Hier liegen deine eigenen Bauteile aus Minecraft: je Kit eine `.schem` (mit WorldEdit gespeichert) und eine `.json` mit demselben Namen, in einem Unterordner je Stil (`medieval`, `fantasy`, `rustic`, `nordic`, `japanese`, `cherry`, `modern`, `mediterranean`) oder in `alle/` für jeden Stil.

Wie du Kits baust, ausrichtest, exportierst und beschreibst: [`docs/DETAIL_KITS.md`](../docs/DETAIL_KITS.md).

Ohne Kits baut der Generator wie bisher.
